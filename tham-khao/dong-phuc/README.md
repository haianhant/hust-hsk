- Áo sơ mi sinh viên (`shirt-white`, `sport-pe`) — sơ mi trắng / xanh nhạt phối quần tối hoặc chân váy đen — nguồn: https://dantri.com.vn/giao-duc/dai-hoc-bach-khoa-ha-noi-trinh-lang-hon-20-mau-dong-phuc-sinh-vien-moi-20221222110735214.htm
