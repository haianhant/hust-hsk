# Ảnh tham khảo — Tòa C1, Đại học Bách khoa Hà Nội

Tòa C1: khối nhà dài màu trắng nằm ngang phía bắc campus, mái sóng, mặt tiền có
lưới hoa gió (gạch thông gió), biển dọc đỏ "ĐẠI HỌC BÁCH KHOA", chữ C1, hành lang
các tầng với lan can đỏ, sảnh và bậc thềm phía trước, sân cỏ trước tòa nhà.
